# Code of Conduct

Be respectful, specific, and constructive.

We welcome disagreement about architecture, evidence, and conclusions. Discuss
the work without attacking the person. Do not harass, threaten, discriminate,
or publish another person's private information.

Project maintainers may edit or remove abusive contributions and may restrict
participation when necessary to keep the project safe and useful.

Report conduct concerns privately to the repository owner rather than opening
a public issue containing sensitive information.
