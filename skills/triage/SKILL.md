# Triage

## Goal

Decide whether a ticket is ready for implementation using only the monitoring
event, ticket, and repository evidence.

## Rules

- Remain read-only.
- Identify concrete relevant files.
- State constraints and risks explicitly.
- Produce one testable success predicate for a ready ticket.
- Escalate when required behavior is ambiguous.
- Never invent acceptance criteria.
- Return only the requested structured output.
