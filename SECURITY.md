# Security

This is an educational repository, and some tagged checkpoints intentionally
contain defective behavior. A documented defect that is part of a scenario is
not a security vulnerability.

Do not include secrets, credentials, personal data, or private production
artifacts in issues, pull requests, fixtures, or run logs.

For an actual vulnerability, contact the repository owner privately with the
affected checkpoint or commit, reproduction steps, impact, and a suggested
mitigation. Avoid public disclosure until the issue has been reviewed.
